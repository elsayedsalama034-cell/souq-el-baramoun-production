# سوق البرامون — الإصدار الاحترافي V9

## ما الذي تم تحسينه؟
- معالجة فتح المشروع محلياً من الهاتف: فتح `index.html` مباشرة يحول إلى `فتح-التطبيق.html` بدلاً من صفحة بيضاء.
- عند تشغيل المشروع عبر Vite أو Firebase Hosting يبقى `index.html` هو نقطة تشغيل React الحقيقية ولا يتم تحويله إلى المعاينة.
- إضافة Web App Manifest وتجهيز المشروع ليعمل كتطبيق ويب قابل للتثبيت.
- إضافة Service Worker لتخزين غلاف التطبيق والعمل بشكل أفضل عند ضعف الاتصال بعد أول تشغيل.
- إضافة أيقونة عربية بسيطة للمشروع.
- الإبقاء على Firebase وFirestore وStorage والمصادقة وإدارة المدير والإعلانات والاشتراكات والإشعارات والفئات والسلايدر.
- إضافة أوامر جاهزة للبناء والنشر في `package.json`.

## مهم
النسخة المحلية `فتح-التطبيق.html` هي معاينة تعمل مباشرة من الهاتف بدون خادم. أما النسخة الحقيقية فهي مشروع React وتحتاج تشغيلها بواسطة Vite أو Firebase Hosting بعد وضع بيانات Firebase في `.env`.

## بيانات Firebase
انسخ `.env.example` إلى `.env` وضع بيانات تطبيق Firebase الحقيقي.

## بناء ونشر
```bash
npm install
npm run build
npm run firebase:deploy
```

لم يتم تضمين مفاتيح Firebase السرية أو كلمات مرور المستخدمين داخل المشروع.
