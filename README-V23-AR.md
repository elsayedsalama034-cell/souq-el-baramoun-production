# سوق البرامون — V23

- الزائر يستطيع تصفح الإعلانات وفتح تفاصيل الإعلان وصفحة المعلن بدون تسجيل دخول.
- تسجيل الدخول مخصص للمدير والمشتركين باستخدام البريد الإلكتروني وكلمة المرور.
- إنشاء الحساب متاح للمشتركين فقط، مع البريد الإلكتروني ورقم الهاتف.
- تسجيل الدخول يبقى محفوظاً على الجهاز باستخدام جلسة Firebase المحلية حتى تسجيل الخروج.
- إضافة استرجاع كلمة المرور عبر البريد الإلكتروني.
- إضافة تغيير كلمة المرور من إعدادات الحساب.
- المدير لا يتم إنشاؤه من التسجيل العام؛ يتم إنشاء حساب المدير واعتماد دوره من Firebase كما هو موضح في ملفات الإعداد.
