# سوق البرامون — الإصدار 13

تم تحسين النسخة مع الحفاظ على الصور الحقيقية التجريبية لكل الفئات. المعاينة المحلية تعرض صوراً حقيقية وعناوين وأسعاراً ومدناً ومشاهدات، مع فلترة بالفئات والبحث وسلايدر متحرك من الشمال إلى اليمين.

البيانات التجريبية مستقلة عن بيانات Firebase الحقيقية ويمكن حذفها من وضع التجربة/لوحة المدير عند بدء إدخال البيانات الفعلية.
