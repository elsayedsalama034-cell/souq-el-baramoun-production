# سوق البرامون — V21

تم نقل المتابعة والتقييم من التخزين المحلي إلى Firebase Firestore.

- متابعة حقيقية لكل معلن داخل `users/{sellerId}/followers/{viewerId}`.
- تقييم حقيقي من 1 إلى 5 داخل `users/{sellerId}/ratings/{viewerId}`.
- منع المستخدم من متابعة أو تقييم نفسه.
- منع تكرار تقييم المستخدم نفسه؛ تعديل التقييم يستبدل تقييمه السابق.
- حساب عدد المتابعين ومتوسط التقييم وعدد التقييمات مباشرة من Firestore.
- صفحة المعلن تعرض الإحصائيات والتقييم والتصنيف والإعلانات.
