# سوق البرامون — بيانات تجريبية كاملة

هذه النسخة تحتوي على بيانات وصور تجريبية موزعة على جميع الفئات حتى يمكن تجربة التطبيق قبل إدخال البيانات الحقيقية.

## البيانات التجريبية
- كل فئة لها وصف خاص بها.
- كل فئة لها معلنون تجريبيون ومعلوماتهم.
- كل فئة لها إعلانات تجريبية وصور وأسعار ومدن ووصف ومشاهدات.
- من صفحة الفئات يمكن فتح بيانات كل فئة ومشاهدة المعلنين والإعلانات.
- من الصفحة الرئيسية يوجد زر لمسح/إخفاء البيانات التجريبية، ويمكن إظهارها مرة أخرى.
- البيانات التجريبية لا تعتبر بيانات المستخدمين الحقيقية ولا تُرفع إلى Firebase.

## السلايدر
السلايدر يعرض الصورة والنص معًا، والحركة الجديدة تدخل من الشمال إلى اليمين، مع أزرار التنقل والنقاط والتشغيل التلقائي.

## البيانات الحقيقية
عند ربط Firebase واستخدام الإعلانات الحقيقية، تكون بيانات Firestore وFirebase Storage هي المصدر الفعلي، ويمكن حذف/إخفاء بيانات العرض التجريبي من التطبيق.
