# سوق البرامون — النسخة الذكية

هذه النسخة مبنية على React وFirebase، وتضيف طبقة بحث وفلترة ذكية وترتيب اقتراحات، مع المحافظة على بنية قاعدة البيانات والصلاحيات.

## ما تم تحسينه
- تشغيل آمن حتى قبل وضع مفاتيح Firebase.
- بحث موحد يدعم اختلاف بعض الحروف العربية.
- فلترة حسب المدينة والحد الأقصى للسعر.
- اقتراحات ذكية تعتمد على المميز والمشاهدات وتطابق البحث.
- صفحة إعدادات الحساب.
- تحسين الفئات.

## Firebase
يظل Firebase هو النظام النهائي: Authentication + Firestore + Storage. لا تضع مفاتيح Firebase الحقيقية داخل GitHub؛ استخدم متغيرات البيئة.
