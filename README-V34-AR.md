# سوق البرامون — الإصدار V34

## إغلاق فني وتحسين الحماية
- الإعلانات العامة تعتمد على حالة اشتراك محفوظة داخل الإعلان، مما يجعل استعلام الصفحة الرئيسية متوافقًا مع قواعد Firestore ولا يحتاج إلى فحص حساب المعلن لكل نتيجة.
- عند إيقاف أو إعادة تفعيل الاشتراك، تتم مزامنة حالة الاشتراك مع إعلانات المعلن.
- عند اعتماد اشتراك جديد، تتم مزامنة تاريخ الانتهاء وحالة الاشتراك مع إعلانات المعلن.
- الإعلانات المميزة لم تعد تعتمد على الفهرس المركب `featuredOrder` في الاستعلام؛ يتم ترتيب النتائج داخل التطبيق.
- تعديل المعلن لإعلانه يعيده إلى حالة المراجعة ولا يسمح له بإبقاء الإعلان منشورًا.
- إنشاء الإعلان يتطلب اشتراكًا نشطًا وتاريخ انتهاء مستقبليًا.
- تاريخ انتهاء الاشتراك الجديد يُحفظ كقيمة زمنية في Firestore.

## قبل اعتبار التطبيق جاهزًا للنشر
- إعداد مشروع Firebase النهائي.
- إنشاء المدير الأول في Firestore.
- تجربة التسجيل، الاشتراك، الدفع، الموافقة، الإعلانات، التعديل والحذف.
- تجربة إيقاف الاشتراك وانتهاء مدته.
- تنفيذ `npm install` ثم `npm run build`.
- تثبيت النسخة المبنية على الهاتف واختبارها.
