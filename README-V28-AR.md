# سوق البرامون — V28

أضيفت صلاحيات المدير لإدارة إعلانات المشتركين بالنيابة عنهم:
- إضافة إعلان واختيار المشترك صاحب الإعلان.
- رفع حتى 30 صورة دفعة واحدة.
- تعديل بيانات الإعلان.
- حذف الإعلان نهائياً.
- إيقاف الإعلان أو إعادة تنشيطه.
- تحويل الإعلان إلى مميز وإدارته من لوحة المدير.
- عند تعديل إعلان منشور يعاد إلى حالة المراجعة حفاظاً على جودة المحتوى.

الإعلان الذي يضيفه المدير يُحفظ باسم المشترك المختار، وليس باسم حساب المدير.
