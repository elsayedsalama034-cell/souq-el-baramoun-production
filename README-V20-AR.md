# سوق البرامون — V20

تم تطوير صفحة المعلن لتكون أقرب إلى صفحة متجر اجتماعية كاملة:

- غلاف وصورة بروفايل.
- الاسم واسم المتجر وبيانات الاتصال.
- زر متابعة المعلن مع حفظ المتابعة على الجهاز.
- تقييم المتجر من نجمة إلى خمس نجوم مع حفظ تقييم المستخدم على الجهاز.
- إحصائيات الإعلانات والمشاهدات والتقييم.
- تقسيم إعلانات المعلن حسب الفئات مع عداد لكل فئة.
- عرض كل إعلانات المعلن المنشورة فقط.
- فتح الإعلان من صفحة المعلن.

> المتابعة والتقييم في هذه النسخة محفوظان محلياً على جهاز المستخدم. يمكن لاحقاً نقلهما إلى Firestore ليصبحا مشتركين بين جميع الأجهزة مع نظام تقييم حقيقي.
