# سوق البرامون — V16

## تحديث بطاقات الإعلانات
- تم جعل الفئة جزءًا أساسيًا وواضحًا داخل كل بطاقة إعلان.
- تظهر أيقونة الفئة + اسم الفئة مثل: 🚗 سيارات.
- إذا كان الإعلان يحتوي على تصنيف فرعي يظهر أيضًا بجوار الفئة.
- بطاقات الإعلانات أصبحت أكبر قليلًا لاستيعاب الفئة والسعر والمعلومات بدون تزاحم.
- يدعم اسم الفئة القادم من Firebase، مع الرجوع إلى بيانات الفئات المحلية عند الحاجة.
- تم تطبيق التعديل على أحدث الإعلانات، الأكثر مشاهدة، المفضلة، وإعلانات عرض الفئة.
- تم إصلاح استيراد أيقونة بطاقة الفئة.

## ملاحظة
الفئات والتصنيفات الفرعية مبنية لتكون قابلة للتوسع، وتتماشى مع الهياكل الشائعة في أسواق الإعلانات المصرية مثل السيارات والعقارات والموبايلات والوظائف والأثاث والإلكترونيات والخدمات وغيرها.
