# سوق البرامون V17

- اسم الفئة يظهر على كل كارت إعلان.
- تمت إضافة الفئة الفرعية عند توفرها.
- صفحة إضافة الإعلان أصبحت تعرض الفئات الفرعية حسب الفئة المختارة.
- يتم حفظ اسم الفئة واسم الفئة الفرعية مع الإعلان.
- تمت إضافة اختيار حالة الإعلان.
- تم توسيع عرض الفئة داخل الكارت بشكل واضح.
- تمت الاستفادة من هيكلة فئات السوق المصري الحالية مثل السيارات والعقارات والموبايلات والوظائف والأثاث والإلكترونيات والخدمات.

ملاحظة: لم يتم إجراء بناء إنتاج كامل في هذه الجولة.
