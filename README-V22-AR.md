# سوق البرامون — V22

- ترتيب الصفحة الرئيسية أصبح: السلايدر الكبير ثم شريط الإعلانات الذهبية المتحرك ثم شريط الفئات.
- شريط ذهبي أفقي متحرك مخصص للإعلانات المميزة المدفوعة.
- الإعلانات الذهبية تظهر فقط إذا كانت مميزة ونشطة، مع اعتبار الإعلان القديم نشطاً افتراضياً.
- المدير يستطيع تقديم الإعلان أو تأخيره، إيقافه مؤقتاً، إعادة تنشيطه، أو إزالته من الإعلانات المميزة دون حذف الإعلان نفسه.
- زر تمييز الإعلان في لوحة الإعلانات يفعّل حالة الإعلان الذهبي المدفوع.
