# سوق البرامون — نسخة إنتاجية جاهزة للربط

هذه النسخة تطوّر المشروع إلى تطبيق سوق فعلي بواجهة عربية RTL، مع Firebase ورفع الصور وطلبات الاشتراك عبر فودافون كاش وتفعيل المدير اليدوي.

## ما تم تجهيزه
- تسجيل دخول وإنشاء حساب برقم الهاتف + كلمة مرور بدون رمز تحقق ظاهر للمستخدم.
- حفظ بيانات المستخدمين والأدوار في Firestore.
- المعلن ينشئ إعلاناً ويرفع صوراً إلى Firebase Storage، والإعلان يبدأ بحالة «قيد المراجعة».
- المدير يوافق/يخفي/يحذف الإعلانات ويحدد الإعلان المميز.
- الصفحة الرئيسية تجلب الإعلانات المنشورة من Firestore وتعرض المميزة في سلايدر متحرك تلقائياً.
- عداد المشاهدات.
- طلب اشتراك شهري/مدد مختلفة مع فودافون كاش فقط.
- رقم استقبال التحويلات مضبوط على الرقم الذي حدده صاحب المشروع: 01064788470.
- إمكانية إرفاق صورة التحويل ورقم العملية، ويظل الطلب «قيد المراجعة» حتى يفعّله المدير.
- قواعد Firestore وStorage مقيّدة بحيث لا يستطيع المستخدم العادي منح نفسه صلاحيات المدير أو اعتماد إعلانه بنفسه.

## قبل التشغيل الإنتاجي
1. افتح مشروع Firebase باسم `souq-el-baramoun`.
2. فعّل Authentication > Sign-in method > Email/Password. التطبيق يستخدم هوية داخلية مبنية على رقم الهاتف حتى يحصل المستخدم على تجربة رقم + كلمة مرور بدون OTP.
3. أنشئ Firestore Database وStorage.
4. انسخ `.env.example` إلى `.env` وضع بيانات تطبيق الويب من إعدادات Firebase.
5. انشر `firestore.rules` و`storage.rules` إلى Firebase.
6. أنشئ أول مدير يدوياً من Firebase Authentication ثم أنشئ له مستنداً في `users` بنفس UID واجعل:
   - `role: "admin"`
   - `active: true`
   - `name`: اسم المدير
   - `phone`: رقم المدير
7. بعد ذلك يستطيع المدير إدارة الإعلانات والمراجعة.

## التشغيل والبناء
```bash
npm install
npm run dev
npm run build
```

## النشر
بعد `npm run build` يصبح مجلد `dist` جاهزاً للنشر على Firebase Hosting أو أي استضافة ثابتة.

## ملاحظة أمنية مهمة
لا تضع مفاتيح خدمة Firebase Admin أو مفاتيح حسابات خادم داخل ملفات الواجهة. بيانات Firebase Web config ليست سراً، لكن حماية البيانات تتم عبر Authentication وقواعد Firestore/Storage.

## Android
المشروع React/Vite ويمكن تغليفه كتطبيق Android باستخدام Capacitor بعد نجاح نسخة الويب الإنتاجية. يفضّل اختبار المصادقة ورفع الصور والإشعارات على جهاز حقيقي قبل إصدار APK.
