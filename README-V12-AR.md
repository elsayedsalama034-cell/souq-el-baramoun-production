# سوق البرامون — الإصدار 12

## ما الجديد
- كل فئة تحتوي على بيانات تجريبية مستقلة: معلنين، معلومات، إعلانات، أسعار، مدن، مشاهدات وصور.
- يمكن إخفاء بيانات فئة واحدة من صفحة الفئات، ثم إظهارها مرة أخرى في أي وقت.
- يوجد زر لإخفاء كل البيانات التجريبية دفعة واحدة.
- البيانات التجريبية لا تختلط ببيانات Firebase الحقيقية.
- السلايدر يتحرك باتجاه الشمال إلى اليمين، مع صورة ونص الإعلان والحركة والأسهم والنقاط.
- عند بدء إدخال البيانات الحقيقية يمكن إخفاء التجريبي والاستمرار على بيانات Firebase.

## ملاحظة مهمة
البيانات التجريبية الحالية هي بيانات معاينة داخل المشروع وليست سجلات Firebase حقيقية. زر "مسح البيانات التجريبية" يخفيها من الواجهة ولا يحذف بيانات المستخدمين الحقيقية.
