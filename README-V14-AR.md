# سوق البرامون — V14

## تحديث الفئات
تم توسيع قاعدة الفئات التجريبية لتشمل عشرات الأقسام الرئيسية المناسبة لسوق مصري محلي، مع فئات فرعية ووصف لكل قسم وبيانات تجريبية للمعلنين والإعلانات.

الفئات تشمل: السيارات، الموبايلات والتابلت، العقارات، الأثاث والديكور، الإلكترونيات والأجهزة المنزلية، الخدمات، الوظائف، الموتوسيكلات، النقل والمركبات التجارية، قطع الغيار، الكمبيوتر واللابتوب، الألعاب، الكاميرات، الأجهزة الكهربائية، الملابس، الجمال، الذهب والمجوهرات، الحيوانات والطيور، الأطعمة، المطاعم والكافيهات، الصحة، التعليم، الرياضة، الدراجات، المنزل والحديقة، العدد والأدوات، المقاولات ومواد البناء، التجاري والصناعي، الزراعة والمواشي، الكتب، الهوايات، الآلات الموسيقية، السفر والسياحة، الحفلات والمناسبات، التذاكر والقسائم، المستلزمات المكتبية، خدمات الأعمال، النقل والشحن، وأخرى.

## مصدر بناء قائمة الفئات
تمت مراجعة تصنيفات منصات الإعلانات المبوبة المصرية العامة أثناء إعداد القائمة، مع تكييفها للسوق المحلي وعدم نسخ محتوى إعلانات بعينه.

## البيانات التجريبية
لكل فئة جديدة إعلان تجريبي ومعلن تجريبي. يمكن إخفاء بيانات الفئة أو حذف البيانات التجريبية لاحقًا قبل إدخال البيانات الحقيقية.


### تحديث الإصدار 15
- تمت إضافة اسم الفئة بشكل واضح على كل كرت إعلان، أسفل عنوان الإعلان مباشرة.
- إذا كان الإعلان القادم من Firebase ولا يحتوي على اسم الفئة النصي، يتم استخراج اسمها تلقائيًا من معرّف الفئة الموجود في قائمة الفئات.
- تم زيادة مساحة جسم الكرت قليلًا حتى يظهر اسم الفئة والسعر والمعلومات بدون تزاحم.
